# CopyPaste Pro

CopyPaste Pro — React + Vite + Tailwind PWA.

## Features

- Multi-item clipboard with history
- Rich text paste with formatting preservation
- Snippet management and organization
- PWA support for offline use
- Keyboard shortcuts for quick access

## Tech Stack

React · Vite · Tailwind CSS · PWA

## Quick Start

```bash
git clone https://github.com/D-VKITZ/copypaste-pro.git
cd copypaste-pro
npm install
npm run dev
```
